# Tactics

Tactics is a Top Down Shooter heavily Inspired by Valorant.
The Player is assumed to always aim at head level as they are traversing the Map and playing the Game.
The only real difference to Valorant should be the Camera Angle, which has implications on the Shooting System, where the Goal is to have it be as true to how a Pro Player would play Valorant as possible. Meaning they are always at Head Level, everything else is up to the Player to decide.

Currently this Game is still in progress we are currently at version "4" which is a lie, there have been several other versions before this that have all been scraped, because of different issues, mostly relating to the Netcode.

This Version of Tactics uses Unities Netcode for GameObjects which allows me to have the most controll. The Game will be played with up to 10 players simultaniously.
Initial Versions will be using one of the Players Computers as Host while other connect to it as Clients.
Future plans are to create a dedicated Host for other players to connect to.
